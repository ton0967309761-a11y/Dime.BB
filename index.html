วิธินำไฟล์นี้ไปเปิดใช้ผ่าน GitHub Pages ฟรี!

  1. สร้างไฟล์ index.html: คัดลอกโค้ดทั้งหมดในหน้านี้ แล้วตั้งชื่อไฟล์ว่า index.html
  2. สร้าง Repository บน GitHub: ไปที่ GitHub.com คลิก + New Repository
  3. อัปโหลดไฟล์: ตั้งชื่อโฟลเดอร์ เช่น my-stocks-tracker ตั้งเป็น Public แล้วกด Create -> ลากไฟล์ index.html เข้าไปวาง
  4. เปิดใช้ GitHub Pages:
    • ไปที่แถบ Settings ของ Repository นั้น
    • เลือกเมนู Pages ด้านซ้ายมือ
    • ตรง Branch ให้เลือกเป็น main (หรือ master) แล้วกด Save
  5. พร้อมใช้งาน: รอประมาณ 1 นาที จะได้ URL เว็บไซต์ฟรี นำไปเปิดติดตามราคาหุ้นบนมือถือได้ทันทีตลอดเวลา!
